# Protótipo Vitrinei

gerar um app demo da ferramenta para apresentação a investidores

1.Visão do MEI (Painel ERP): Focado na gestão financeira, estoque dropchip e acompanhamento de vendas vindas do ecossistema.2.Visão do Cliente Final (App de Benefícios): Focado na jornada de assinatura, escolha de planos, acionamento de serviços e compra de produtos com desconto.3.Visão Híbrida (Landing Page + Demo): Uma página que explica o negócio e permite navegar entre as funcionalidades principais dos dois lados.

Além disso, como você mencionou um "mini ERP", eu recomendo utilizarmos o scaffold web-db-user (Vite + React + Tailwind + Database). Isso nos permitirá simular o login, a troca de planos e a persistência de dados (como saldo e estoque) durante a apresentação.

1.Landing Page: Explicando o ecossistema e os planos.
2.Painel do MEI: Gestão de vendas, estoque dropchip e financeiro.
3.App do Cliente: Escolha de planos, catálogo de serviços/produtos e aplicação de descontos em tempo real.Ao final, fornecerei o link de acesso público para que você possa apresentar aos investidores.
